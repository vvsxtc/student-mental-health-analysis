# Student Mental Health & Academic Performance Analysis

## Overview

This project explores relationships between sleep, stress level, study hours, and academic performance using a fictional 8-student practice dataset.

The goal was to practice an end-to-end data analytics workflow, from organizing and analyzing data to creating visualizations and communicating findings.

## Tools Used

* Google Sheets
* SQL
* Python
* Pandas
* Matplotlib
* Tableau Public

## Key Questions

* How does academic performance vary across stress levels?
* How do sleep hours vary across stress levels?
* Is there a relationship between sleep hours and academic scores?
* How do study hours differ across stress levels?

## Key Findings

* Average sleep duration: **6.25 hours**
* Average academic score: **79.5**
* High-stress students: **3**
* Medium-stress students: **2**
* Low-stress students: **3**
* The low-stress group had the highest average academic score in this dataset.
* Sleep hours and academic scores showed a strong positive relationship in this small dataset.

## Limitations

This is a small fictional practice dataset containing only 8 students. The results are intended for learning and portfolio demonstration purposes and should not be interpreted as evidence that sleep or stress directly causes changes in academic performance.
